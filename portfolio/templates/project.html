PROJECT 01

Water Quality Analytics Using Machine Learning

Developed a machine learning application to classify water as potable or non-potable based on water quality parameters.

Key Features

  • Developed a machine learning application to classify water as potable or non-potable.
  • Applied SMOTE to handle class imbalance.
  • Used CatBoost, XGBoost, and LightGBM models.
  • Combined the models using a Soft Voting Ensemble approach.
  • Built a Flask-based web application for real-time prediction.

Technologies Used

Python Machine Learning CatBoost XGBoost LightGBM Flask

PROJECT 02

Job Portal & Recruitment Management System

Developed a web-based recruitment platform using Python and Django to connect job seekers and recruiters. The system provides features for job posting, job searching, and online job applications.

Key Features

  • Implemented user authentication for job seekers and recruiters.
  • Developed job posting and job search functionality.
  • Implemented online job application functionality.
  • Used Django ORM and MySQL to manage users, job listings, applications, and recruitment data.
  • Implemented role-based access for job seekers and recruiters.
  • Designed dynamic web pages using Django Templates, HTML, CSS, and JavaScript.

Technologies Used

Python Django MySQL HTML CSS JavaScript
